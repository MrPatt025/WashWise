# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that
works with multi-package repos, or single-package repos to help you version and publish your code.

## Adding a Changeset

To add a changeset, run:

```bash
pnpm changeset
```

This will prompt you to:
1. Select which packages have changed
2. Choose the type of change (major, minor, patch)
3. Write a summary of the changes

## Publishing Changes

When you're ready to release:

```bash
# Create version updates
pnpm changeset version

# Publish to npm (if public)
pnpm changeset publish
```

## Changeset Types

- **major**: Breaking changes (1.0.0 → 2.0.0)
- **minor**: New features, backward compatible (1.0.0 → 1.1.0)
- **patch**: Bug fixes, backward compatible (1.0.0 → 1.0.1)
